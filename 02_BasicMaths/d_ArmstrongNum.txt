================================================================================
QUESTION: Armstrong Number
FILE: d_ArmstrongNum.java
================================================================================

1. WHAT IS THIS PROBLEM ABOUT?
--------------------------------------------------------------------------------
Check if a number is an Armstrong number (also known as a Narcissistic number). An N-digit number is an Armstrong number if the sum of its digits raised to the power of N equals the original number itself (e.g., 153 = 1^3 + 5^3 + 3^3 = 1 + 125 + 27 = 153).

2. HOW TO THINK (INTUITION)?
--------------------------------------------------------------------------------
1. Count how many digits the number has (let this count be K).
2. Extract each digit one by one.
3. Raise each digit to the power of K and add to a running sum.
4. If the final sum equals the original number, it is an Armstrong number!

3. STEP-BY-STEP APPROACH
--------------------------------------------------------------------------------
1. Calculate digit count K:
   - K = (int) Math.floor(Math.log10(num)) + 1.
2. Initialize sum = 0, copy = num.
3. Loop while copy > 0:
   - digit = copy % 10.
   - sum += Math.pow(digit, K).
   - copy /= 10.
4. Return (sum == num).

4. WHY THIS WORKS?
--------------------------------------------------------------------------------
It follows the exact mathematical definition of an Armstrong number: sum of (each digit ^ total digits) == number.

5. WHY NOT OTHER APPROACHES (WHY NOT THAT)?
--------------------------------------------------------------------------------
Why not assume K is always 3?
Numbers can have any number of digits! 153 has 3 digits (1^3 + 5^3 + 3^3), but 1634 has 4 digits (1^4 + 6^4 + 3^4 + 4^4 = 1634). Computing K dynamically makes the code work for all numbers.

6. STEP-BY-STEP DRY RUN
--------------------------------------------------------------------------------
Input: num = 153
K = log10(153) + 1 = 2 + 1 = 3 digits.
- digit 3: 3^3 = 27 -> sum = 27
- digit 5: 5^3 = 125 -> sum = 27 + 125 = 152
- digit 1: 1^3 = 1 -> sum = 152 + 1 = 153
Check: sum (153) == num (153) -> TRUE! 153 is an Armstrong number.

7. COMPLEXITY ANALYSIS
--------------------------------------------------------------------------------
- Time Complexity: O(log10(N))
  Reason: Loop runs once per digit of N.
- Space Complexity: O(1)
  Reason: Constant extra memory.

8. IMPORTANT TIPS, TRAPS & EDGE CASES
--------------------------------------------------------------------------------
- Be careful with integer conversion: Math.pow() returns a double, so cast to int if needed.
- Don't mutate the original number during the digit extraction loop, or you won't be able to compare it at the end!
