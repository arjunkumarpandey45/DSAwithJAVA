=========================
RECURSION IN JAVA - 25 IMPORTANT POINTS + TRAPS
=========================

1. What is Recursion?
- A method calling itself is called recursion.

Example:
public static void fun(int n){
    if(n == 0) return;
    fun(n - 1);
}

TRAP:
- Recursion is NOT just loop replacement.
- Used in Tree, Graph, Backtracking, Divide & Conquer.


2. Base Case (Most Important)
- Every recursive function must have a stopping condition.

Example:
if(n == 0) return;

TRAP:
- No base case = Infinite recursion
- Causes StackOverflowError


3. Recursive Case
- Part where function calls itself.

Example:
fun(n - 1);

Formula:
Base Case + Recursive Case = Recursion


4. Stack Memory
- Recursion uses CALL STACK memory.
- Every function call goes into stack.

Example:
fun(3)
fun(2)
fun(1)
fun(0)

TRAP:
- Mostly uses stack memory, not heap.


5. Dry Run is Mandatory
- Always trace recursion step by step.

Example:
fun(3)

Call Stack:
fun(3)
  fun(2)
    fun(1)
      fun(0)


6. Two Phases of Recursion
A) Forward Phase
- Calls go deeper

B) Backtracking Phase
- Function returns upward


7. Before vs After Recursive Call

Before:
System.out.print(n);
fun(n - 1);

Output:
3 2 1

After:
fun(n - 1);
System.out.print(n);

Output:
1 2 3

TRAP:
- Position changes output.


8. Recursive Tree
- Every recursive call creates branches.

Example:
fib(5)

fib(5)
├── fib(4)
│   ├── fib(3)
│   └── fib(2)
└── fib(3)


9. Time Complexity
- Some recursive solutions are expensive.

Example:
Fibonacci

TC = O(2^n)

TRAP:
- Recursion can be slow.


10. Space Complexity
- Stack memory also counts.

Example:
factorial(n)

SC = O(n)


11. Recursion ≠ Always Better
- Loop can be more memory efficient.

Example:
Factorial using loop is often better.


12. Tail Recursion
- Recursive call is last statement.

Example:
fun(n - 1);

TRAP:
- Java does NOT optimize tail recursion.


13. Head Recursion
- Recursive call happens first.

Example:
fun(n - 1);
System.out.println(n);


14. Tree Recursion
- Function calls itself multiple times.

Example:
fib(n-1) + fib(n-2)


15. Indirect Recursion
- One function calls another function.

Example:
fun1() → fun2()
fun2() → fun1()


16. Direct Recursion
- Function directly calls itself.

Example:
fun();


17. StackOverflowError
- Too many recursive calls crash program.

Example:
fun(10000000);

Output:
StackOverflowError


18. Recursive Relation
- Convert big problem into smaller problem.

Example:
5! = 5 × 4!


19. Important Recursion Problems
1. Factorial
2. Fibonacci
3. Sum of N numbers
4. Reverse String
5. Power
6. Palindrome
7. Binary Search
8. Tower of Hanoi
9. Subsequence
10. Backtracking


20. Binary Search Recursion
- Divide problem into half.

TC = O(log n)


21. Backtracking Uses Recursion
Examples:
- N Queen
- Sudoku
- Maze
- Permutations

Formula:
Choose → Explore → Undo


22. Recursive Thinking Formula
Ask:
1. Smallest problem?
2. Base case?
3. Smaller subproblem?
4. Combine result?


23. Parameter Must Change

Wrong:
fun(n);

Correct:
fun(n - 1);

TRAP:
- Same parameter = Infinite recursion


24. Return Type Mistake

Wrong:
public static int sum(int n){
    sum(n - 1);
}

Correct:
public static int sum(int n){
    return n + sum(n - 1);
}


25. Golden Rule of Recursion
Always ask:

1. Base case?
2. Smaller problem?
3. Is input reducing?

If YES → Recursion can work.


=========================
TOP 7 RECURSION TRAPS
=========================

1. Forgetting base case
2. Wrong return statement
3. Parameter not decreasing
4. Confusing before/after recursion
5. Ignoring stack memory
6. Thinking recursion is always efficient
7. Not doing dry run


=========================
RECURSION TEMPLATE
=========================

public static void recursion(int n){

    // Base Case
    if(n == 0){
        return;
    }

    // Work

    recursion(n - 1);

    // Optional work after recursion
}
