================================================================================
QUESTION: Move Zeroes to End (LeetCode 283)
FILE: b_MoveZero.java
================================================================================

1. WHAT IS THIS PROBLEM ABOUT?
--------------------------------------------------------------------------------
Move all zeroes in an array to the end while keeping the relative order of non-zero elements unchanged.
Must be done in-place without making a copy of the array.

2. HOW TO THINK (INTUITION)?
--------------------------------------------------------------------------------
Imagine you have a pointer `j` waiting at the first zero.
Now take an explorer pointer `i` that walks ahead looking for non-zero numbers.
Whenever `i` finds a non-zero number, swap it with the zero at `j`!
Then advance `j` to the next spot. Repeat until the end!

3. STEP-BY-STEP APPROACH
--------------------------------------------------------------------------------
1. Find the index of the first zero and store it in j.
2. If no zero exists, return (array is already good).
3. Loop with i from j + 1 to n - 1:
   - If arr[i] != 0:
     - Swap arr[i] with arr[j].
     - Increment j (j++).
4. Done!

4. WHY THIS WORKS?
--------------------------------------------------------------------------------
Pointer `j` always points to the earliest zero available. When a non-zero element is swapped into `j`, it preserves the order of non-zeroes, and zeroes get pushed forward.

5. WHY NOT OTHER APPROACHES (WHY NOT THAT)?
--------------------------------------------------------------------------------
Why not collect all non-zeroes into a new ArrayList, then fill remaining with zeros?
That uses O(N) extra space. The two-pointer swap approach uses O(1) extra space.

6. STEP-BY-STEP DRY RUN
--------------------------------------------------------------------------------
arr = [0, 1, 0, 3, 12]
First zero is at index j = 0.
i = 1: arr[1] = 1 != 0 -> swap arr[1] and arr[0] -> [1, 0, 0, 3, 12], j becomes 1
i = 2: arr[2] = 0 (skip)
i = 3: arr[3] = 3 != 0 -> swap arr[3] and arr[1] -> [1, 3, 0, 0, 12], j becomes 2
i = 4: arr[4] = 12 != 0 -> swap arr[4] and arr[2] -> [1, 3, 12, 0, 0], j becomes 3
Result: [1, 3, 12, 0, 0]

7. COMPLEXITY ANALYSIS
--------------------------------------------------------------------------------
- Time Complexity: O(N)
  Reason: Single pass of two pointers through the array.
- Space Complexity: O(1)
  Reason: In-place swapping with two pointers.

8. IMPORTANT TIPS, TRAPS & EDGE CASES
--------------------------------------------------------------------------------
- If array has NO zeroes (e.g. [1, 2, 3]), handle it by checking if j == -1 and returning early.
