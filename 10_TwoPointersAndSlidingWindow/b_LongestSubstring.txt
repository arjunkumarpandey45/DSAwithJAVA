================================================================================
QUESTION: Longest Substring Without Repeating Characters (LeetCode 3)
FILE: b_LongestSubstring.java
================================================================================

1. WHAT IS THIS PROBLEM ABOUT?
--------------------------------------------------------------------------------
Given a string s, find the length of the longest substring without repeating characters.

2. HOW TO THINK (INTUITION)?
--------------------------------------------------------------------------------
Use a sliding window [left, right] and a Map storing the last seen index of each character.
Expand `right` pointer one character at a time.
If character `s.charAt(right)` was already seen at index `prev` AND `prev >= left`:
Duplicate detected inside our window! Jump `left` forward to `prev + 1`!
Update character's latest index and update `maxLen = Math.max(maxLen, right - left + 1)`.

3. STEP-BY-STEP APPROACH
--------------------------------------------------------------------------------
1. Map<Character, Integer> map = new HashMap<>(); (or int[] hash = new int[256] initialized to -1)
2. int left = 0, right = 0, maxLen = 0, n = s.length();
3. while (right < n):
   - char ch = s.charAt(right);
   - if (map.containsKey(ch) && map.get(ch) >= left):
     - left = map.get(ch) + 1; // jump left past duplicate
   - maxLen = Math.max(maxLen, right - left + 1);
   - map.put(ch, right);
   - right++;
4. Return maxLen.

4. WHY THIS WORKS?
--------------------------------------------------------------------------------
Storing character indices allows `left` to jump directly past the offending duplicate character in O(1) without shrinking step-by-step.

5. WHY NOT OTHER APPROACHES (WHY NOT THAT)?
--------------------------------------------------------------------------------
Why not check all substrings with nested loops?
Nested loops take O(N^2) or O(N^3). Sliding window with index jumping runs in a single pass O(N) time.

6. STEP-BY-STEP DRY RUN
--------------------------------------------------------------------------------
s = "abcabcbb"
r=0 ('a'): left=0, len=1, map={'a':0}
r=1 ('b'): left=0, len=2, map={'a':0, 'b':1}
r=2 ('c'): left=0, len=3, map={'a':0, 'b':1, 'c':2}
r=3 ('a'): 'a' seen at 0 >= left(0) -> left = 0+1 = 1. Window: "bca", len=3, map['a']=3
r=4 ('b'): 'b' seen at 1 >= left(1) -> left = 1+1 = 2. Window: "cab", len=3, map['b']=4
r=5 ('c'): 'c' seen at 2 >= left(2) -> left = 2+1 = 3. Window: "abc", len=3, map['c']=5
r=6 ('b'): 'b' seen at 4 >= left(3) -> left = 4+1 = 5. Window: "b", len=2
r=7 ('b'): 'b' seen at 6 >= left(5) -> left = 6+1 = 7. Window: "b", len=1
Output: 3

7. COMPLEXITY ANALYSIS
--------------------------------------------------------------------------------
- Time Complexity: O(N)
  Reason: Both pointers move strictly forward. Each character processed once.
- Space Complexity: O(min(N, 256))
  Reason: Map holds at most character set size (256 ASCII).

8. IMPORTANT TIPS, TRAPS & EDGE CASES
--------------------------------------------------------------------------------
- Trap: Always check `map.get(ch) >= left`! If a duplicate was seen before `left`, it is outside the current window and must be ignored.
