================================================================================
QUESTION: Number of Substrings Containing All Three Characters (LeetCode 1358)
FILE: e_NumberOfSubstrings.java
================================================================================

1. WHAT IS THIS PROBLEM ABOUT?
--------------------------------------------------------------------------------
Given a string s consisting only of characters a, b and c, return the number of substrings containing at least one occurrence of all three characters.

2. HOW TO THINK (INTUITION)?
--------------------------------------------------------------------------------
As you iterate through string `s` from left to right, keep track of the LAST SEEN index of 'a', 'b', and 'c'.
Suppose at current index `i`, last seen indices are `lastA`, `lastB`, `lastC`.
If all three characters have been seen at least once, what is the smallest (oldest) index among them?
`minLast = min(lastA, lastB, lastC)`.
Notice: EVERY substring ending at index `i` that STARTS at or before `minLast` (indices 0, 1, 2... minLast) contains all three characters!
How many such starting positions exist?
Exactly `minLast + 1` substrings! Just add `minLast + 1` to your total answer!

3. STEP-BY-STEP APPROACH
--------------------------------------------------------------------------------
1. int[] lastSeen = { -1, -1, -1 };
2. int count = 0;
3. For i = 0 to s.length() - 1:
   - lastSeen[s.charAt(i) - 'a'] = i;
   - if (lastSeen[0] != -1 && lastSeen[1] != -1 && lastSeen[2] != -1):
     - count += 1 + Math.min(lastSeen[0], Math.min(lastSeen[1], lastSeen[2]));
4. Return count.

4. WHY THIS WORKS?
--------------------------------------------------------------------------------
The smallest index of the three characters defines the tightest valid window ending at `i`. Any prefix before that index automatically contains all three characters.

5. WHY NOT OTHER APPROACHES (WHY NOT THAT)?
--------------------------------------------------------------------------------
Why not two nested loops checking every substring?
Checking all substrings is O(N^2). This last-seen index formula does it in a single pass O(N) time with O(1) space!

6. STEP-BY-STEP DRY RUN
--------------------------------------------------------------------------------
s = "abcabc"
i=0 ('a'): last=[-0, -1, -1]
i=1 ('b'): last=[0, 1, -1]
i=2 ('c'): last=[0, 1, 2] -> min(0, 1, 2) = 0 -> count += (0 + 1) = 1 (substring "abc")
i=3 ('a'): last=[3, 1, 2] -> min(3, 1, 2) = 1 -> count += (1 + 1) = 2 ("bca", "abca")
i=4 ('b'): last=[3, 4, 2] -> min(3, 4, 2) = 2 -> count += (2 + 1) = 3 ("cab", "bcab", "abcab")
i=5 ('c'): last=[3, 4, 5] -> min(3, 4, 5) = 3 -> count += (3 + 1) = 4
Total = 1 + 2 + 3 + 4 = 10 substrings!

7. COMPLEXITY ANALYSIS
--------------------------------------------------------------------------------
- Time Complexity: O(N)
  Reason: Single pass of length N.
- Space Complexity: O(1)
  Reason: Array of size 3.

8. IMPORTANT TIPS, TRAPS & EDGE CASES
--------------------------------------------------------------------------------
- Using `1 + min(lastA, lastB, lastC)` directly avoids needing any inner while loop to shrink a sliding window.
