================================================================================
QUESTION: Square Root of an Integer (LeetCode 69)
FILE: i_SquareRoot.java
================================================================================

1. WHAT IS THIS PROBLEM ABOUT?
--------------------------------------------------------------------------------
Compute and return the integer square root of non-negative integer x: floor(sqrt(x)) without using built-in exponent functions.

2. HOW TO THINK (INTUITION)?
--------------------------------------------------------------------------------
The answer must lie in the range 1 to x.
Because squares are monotonically increasing (1, 4, 9, 16, 25...), binary search on this range:
At `mid`:
- If `mid * mid <= x`: `mid` could be our answer! Save `ans = mid`, search right (`low = mid + 1`) to see if a larger integer works.
- If `mid * mid > x`: `mid` is too large, search left (`high = mid - 1`).

3. STEP-BY-STEP APPROACH
--------------------------------------------------------------------------------
1. if (x <= 1) return x;
2. long low = 1, high = x / 2, ans = 1;
3. while (low <= high):
   - long mid = low + (high - low) / 2;
   - if (mid * mid <= x): ans = mid; low = mid + 1;
   - else: high = mid - 1;
4. Return (int) ans.

4. WHY THIS WORKS?
--------------------------------------------------------------------------------
The function f(m) = m^2 is monotonic. Finding the largest integer where m^2 <= x is the textbook definition of floor(sqrt(x)).

5. WHY NOT OTHER APPROACHES (WHY NOT THAT)?
--------------------------------------------------------------------------------
Why not linear search from 1 to x?
For x = 2 * 10^9, sqrt(x) ~ 46,340. Binary search takes only 16 operations instead of 46,340.

6. STEP-BY-STEP DRY RUN
--------------------------------------------------------------------------------
x = 28
low = 1, high = 14
- mid = 7: 7*7 = 49 > 28 -> high = 6
- mid = 3: 3*3 = 9 <= 28 -> ans = 3, low = 4
- mid = 5: 5*5 = 25 <= 28 -> ans = 5, low = 6
- mid = 6: 6*6 = 36 > 28 -> high = 5 < low -> STOP!
Ans = 5 (since 5^2 = 25 <= 28 < 6^2 = 36).

7. COMPLEXITY ANALYSIS
--------------------------------------------------------------------------------
- Time Complexity: O(log x)
  Reason: Halves the range [1...x/2].
- Space Complexity: O(1)
  Reason: Only primitive variables.

8. IMPORTANT TIPS, TRAPS & EDGE CASES
--------------------------------------------------------------------------------
- ALWAYS use `long` for `mid` and `mid * mid`! If `mid = 1,000,000`, `mid * mid = 10^12` which overflows 32-bit int into negative numbers.
