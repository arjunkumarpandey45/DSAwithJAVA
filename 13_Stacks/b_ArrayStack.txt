================================================================================
QUESTION: Implement Stack Using Array
FILE: b_ArrayStack.java
================================================================================

1. WHAT IS THIS PROBLEM ABOUT?
--------------------------------------------------------------------------------
Implement a fixed-size Stack data structure using a standard primitive array without using any Java collections.

2. HOW TO THINK (INTUITION)?
--------------------------------------------------------------------------------
Use an array `arr` of size `capacity` and an integer `top` initialized to -1.
- Push: increment `top`, place element at `arr[top]`.
- Pop: retrieve `arr[top]`, decrement `top`.
- Peek: return `arr[top]`.
- Empty: `top == -1`.
- Full: `top == capacity - 1`.

3. STEP-BY-STEP APPROACH
--------------------------------------------------------------------------------
1. class Stack { int[] arr; int top; int capacity; }
2. push(val): if (top == capacity - 1) print "Overflow"; else arr[++top] = val;
3. pop(): if (top == -1) print "Underflow"; else return arr[top--];
4. peek(): if (top == -1) return -1; else return arr[top];

4. WHY THIS WORKS?
--------------------------------------------------------------------------------
Index `top` tracks the boundary of active elements. Moving `top` up and down simulates pushing and popping in O(1) time.

5. WHY NOT OTHER APPROACHES (WHY NOT THAT)?
--------------------------------------------------------------------------------
Disadvantage of Array Stack:
Fixed capacity! Once full, push causes Stack Overflow unless dynamic resizing is implemented.

6. STEP-BY-STEP DRY RUN
--------------------------------------------------------------------------------
top = -1, cap = 3
push(10) -> top=0, arr[0]=10
push(20) -> top=1, arr[1]=20
pop() -> returns arr[1]=20, top becomes 0
peek() -> returns arr[0]=10

7. COMPLEXITY ANALYSIS
--------------------------------------------------------------------------------
- Time Complexity: O(1) for all operations
  Reason: Direct array indexing.
- Space Complexity: O(N)
  Reason: Fixed array allocation.

8. IMPORTANT TIPS, TRAPS & EDGE CASES
--------------------------------------------------------------------------------
- Check for Overflow (`top == capacity - 1`) on push and Underflow (`top == -1`) on pop.
