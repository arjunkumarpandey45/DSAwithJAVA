================================================================================
QUESTION: Remove K Digits (LeetCode 402)
FILE: q_RemoveKDigits.java
================================================================================

1. WHAT IS THIS PROBLEM ABOUT?
--------------------------------------------------------------------------------
Given string num representing a non-negative integer and an integer k, return the smallest possible integer after removing k digits from num.

2. HOW TO THINK (INTUITION)?
--------------------------------------------------------------------------------
To make a number as small as possible, digits at higher place values (leftmost digits) must be as small as possible!
Greedy principle: If you see a smaller digit following a larger digit, REMOVE the larger digit!
Use a monotonic increasing stack:
- While `k > 0` and `st.peek() > currentDigit`: pop stack, decrement `k`!
- Push currentDigit.
- After loop, if `k > 0`, pop remaining digits from end.
- Remove leading zeroes and return string.

3. STEP-BY-STEP APPROACH
--------------------------------------------------------------------------------
1. Stack<Character> st = new Stack<>();
2. For char c in num.toCharArray():
   - while (!st.isEmpty() && k > 0 && st.peek() > c): st.pop(); k--;
   - st.push(c);
3. while (k > 0 && !st.isEmpty()): st.pop(); k--;
4. Build string, strip leading zeroes.
5. Return sb.length() == 0 ? "0" : sb.toString();

4. WHY THIS WORKS?
--------------------------------------------------------------------------------
A digit at position `i` is worth 10x more than a digit at position `i + 1`. Removing an inversion `d[i] > d[i + 1]` always yields a smaller number.

5. WHY NOT OTHER APPROACHES (WHY NOT THAT)?
--------------------------------------------------------------------------------
Why not combinations?
Removing k out of N digits has (N choose k) combinations (exponential). Monotonic stack is O(N) linear time.

6. STEP-BY-STEP DRY RUN
--------------------------------------------------------------------------------
num = "1432219", k = 3
- 1: push 1 -> st=[1]
- 4: 4 > 1 -> push 4 -> st=[1, 4]
- 3: 4 > 3 -> pop 4, k=2 -> push 3 -> st=[1, 3]
- 2: 3 > 2 -> pop 3, k=1 -> push 2 -> st=[1, 2]
- 2: push 2 -> st=[1, 2, 2]
- 1: 2 > 1 -> pop 2, k=0 -> push 1 -> st=[1, 2, 1]
- 9: push 9 -> st=[1, 2, 1, 9]
Result: "1219"

7. COMPLEXITY ANALYSIS
--------------------------------------------------------------------------------
- Time Complexity: O(N)
  Reason: Each digit pushed and popped at most once.
- Space Complexity: O(N)
  Reason: Stack storing digits.

8. IMPORTANT TIPS, TRAPS & EDGE CASES
--------------------------------------------------------------------------------
- Remember to strip leading zeroes (e.g. num = "10200", k = 1 -> "0200" becomes "200").
- If all digits are removed, return "0", NOT "".
