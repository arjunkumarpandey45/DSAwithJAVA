================================================================================
QUESTION: Maximum Depth of Binary Tree (LeetCode 104)
FILE: e_MaxDepth.java
================================================================================

1. WHAT IS THIS PROBLEM ABOUT?
--------------------------------------------------------------------------------
Find the maximum depth (number of nodes along the longest path from the root node down to the farthest leaf node).

2. HOW TO THINK (INTUITION)?
--------------------------------------------------------------------------------
Depth of an empty tree is 0.
Depth of any node is: `1 + Math.max(depth of left child, depth of right child)`!
A one-line recursive solution.

3. STEP-BY-STEP APPROACH
--------------------------------------------------------------------------------
public int maxDepth(TreeNode root) {
    if (root == null) return 0;
    return 1 + Math.max(maxDepth(root.left), maxDepth(root.right));
}

4. WHY THIS WORKS?
--------------------------------------------------------------------------------
The longest path from a node to any leaf is 1 step (the node itself) plus the longest path through either its left or right subtree.

5. WHY NOT OTHER APPROACHES (WHY NOT THAT)?
--------------------------------------------------------------------------------
BFS level-order can also count depth (number of while-loop iterations), but recursion is clean and uses O(H) stack rather than O(W) queue.

6. STEP-BY-STEP DRY RUN
--------------------------------------------------------------------------------
Tree: 3 -> left: 9, right: 20 -> 20 has (15, 7)
maxDepth(15) = 1, maxDepth(7) = 1
maxDepth(20) = 1 + max(1, 1) = 2
maxDepth(9) = 1
maxDepth(3) = 1 + max(1, 2) = 3!

7. COMPLEXITY ANALYSIS
--------------------------------------------------------------------------------
- Time Complexity: O(N)
  Reason: Visits every node once.
- Space Complexity: O(H)
  Reason: Recursion stack depth equal to height of tree.

8. IMPORTANT TIPS, TRAPS & EDGE CASES
--------------------------------------------------------------------------------
- Base case `if (root == null) return 0;` must be first.
