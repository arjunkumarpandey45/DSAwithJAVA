================================================================================
QUESTION: Diameter of Binary Tree (LeetCode 543)
FILE: g_diameterOfBinaryTree.java
================================================================================

1. WHAT IS THIS PROBLEM ABOUT?
--------------------------------------------------------------------------------
The diameter of a binary tree is the length of the longest path between any two nodes in a tree. This path may or may not pass through the root.

2. HOW TO THINK (INTUITION)?
--------------------------------------------------------------------------------
At any node, what is the longest path that has this node as its turning curve?
`pathLength = leftHeight + rightHeight`!
As we compute tree heights recursively, we can update a global maximum diameter at every single node seen!
Return height: `1 + Math.max(leftHeight, rightHeight)` to parent.

3. STEP-BY-STEP APPROACH
--------------------------------------------------------------------------------
1. int[] diameter = new int[1];
2. height(root, diameter):
   - if (root == null) return 0;
   - int lh = height(root.left, diameter);
   - int rh = height(root.right, diameter);
   - diameter[0] = Math.max(diameter[0], lh + rh); // curve through this node
   - return 1 + Math.max(lh, rh);
3. Call height(root, diameter), return diameter[0].

4. WHY THIS WORKS?
--------------------------------------------------------------------------------
Every path in a tree has a unique highest node (the LCA of its two endpoints). Evaluating `lh + rh` at every node checks all possible paths in O(N) time.

5. WHY NOT OTHER APPROACHES (WHY NOT THAT)?
--------------------------------------------------------------------------------
Calculating `height(left) + height(right)` separately for each node takes O(N^2). Updating diameter inside the height function takes O(N).

6. STEP-BY-STEP DRY RUN
--------------------------------------------------------------------------------
Tree: 1 with left: 2 (children 4, 5), right: 3
Node 4: lh=0, rh=0 -> h=1, diam=0
Node 5: lh=0, rh=0 -> h=1, diam=0
Node 2: lh=1, rh=1 -> diam = max(0, 1+1=2), h = 1+max(1,1) = 2
Node 3: h=1
Node 1: lh=2, rh=1 -> diam = max(2, 2+1=3), h = 3
Result Diameter = 3 (path: 4 -> 2 -> 1 -> 3)

7. COMPLEXITY ANALYSIS
--------------------------------------------------------------------------------
- Time Complexity: O(N)
  Reason: Single postorder pass.
- Space Complexity: O(H)
  Reason: Stack space.

8. IMPORTANT TIPS, TRAPS & EDGE CASES
--------------------------------------------------------------------------------
- Diameter in LeetCode is counted in EDGES (so `lh + rh`). If counted in nodes, it would be `lh + rh + 1`.
