================================================================================
QUESTION: Binary Tree Paths (LeetCode 257)
FILE: i_binaryTreePaths.java
================================================================================

1. WHAT IS THIS PROBLEM ABOUT?
--------------------------------------------------------------------------------
Given the root of a binary tree, return all root-to-leaf paths in any order formatted as "1->2->5".

2. HOW TO THINK (INTUITION)?
--------------------------------------------------------------------------------
DFS Backtracking:
Carry the path string down with you: `path + "->" + root.val`.
When you reach a LEAF node (`root.left == null && root.right == null`):
Add the accumulated path string to the answer list!

3. STEP-BY-STEP APPROACH
--------------------------------------------------------------------------------
1. List<String> ans = new ArrayList<>();
2. if (root != null) dfs(root, "", ans);
3. dfs(root, path, ans):
   - if (root.left == null && root.right == null):
     - ans.add(path + root.val);
     - return;
   - if (root.left != null) dfs(root.left, path + root.val + "->", ans);
   - if (root.right != null) dfs(root.right, path + root.val + "->", ans);

4. WHY THIS WORKS?
--------------------------------------------------------------------------------
Only leaf nodes represent the termination of a root-to-leaf path. Branching to non-null children constructs all complete paths.

5. WHY NOT OTHER APPROACHES (WHY NOT THAT)?
--------------------------------------------------------------------------------
String concatenation inside recursion creates new strings at each level. For massive trees, StringBuilder with explicit backtracking (deleting appended length) saves memory.

6. STEP-BY-STEP DRY RUN
--------------------------------------------------------------------------------
Tree: 1 -> left: 2 (child 5), right: 3
root 1: calls left with "1->", right with "1->"
node 2: calls left child 5 with "1->2->"
node 5: leaf node! ans.add("1->2->5")
node 3: leaf node! ans.add("1->3")
Result: ["1->2->5", "1->3"]

7. COMPLEXITY ANALYSIS
--------------------------------------------------------------------------------
- Time Complexity: O(N * H)
  Reason: Visits N nodes, copying path strings of length up to H.
- Space Complexity: O(H)
  Reason: Recursion stack.

8. IMPORTANT TIPS, TRAPS & EDGE CASES
--------------------------------------------------------------------------------
- Check `root.left == null && root.right == null` for leaf, NOT `root == null`, otherwise a leaf node would add duplicate paths for its null children.
