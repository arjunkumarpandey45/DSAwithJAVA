================================================================================
QUESTION: Left and Right View of Binary Tree (LeetCode 199)
FILE: m_LeftAndRightView.java
================================================================================

1. WHAT IS THIS PROBLEM ABOUT?
--------------------------------------------------------------------------------
Right Side View: What you see when standing on the right side of the tree (first node seen from right at each level).
Left Side View: First node seen from left at each level.

2. HOW TO THINK (INTUITION)?
--------------------------------------------------------------------------------
Clever Recursive DFS:
Pass `level` (starting at 0) and maintain result list `ans`:
Notice: The FIRST time you visit a new level, `ans.size() == level`!
- For RIGHT View: Visit ROOT -> RIGHT -> LEFT (Reverse Preorder)! The first node encountered at any level is guaranteed to be the rightmost node!
- For LEFT View: Visit ROOT -> LEFT -> RIGHT! The first node encountered is the leftmost node!

3. STEP-BY-STEP APPROACH
--------------------------------------------------------------------------------
Right Side View:
1. List<Integer> ans = new ArrayList<>();
2. dfs(root, 0, ans);
3. dfs(node, level, ans):
   - if (node == null) return;
   - if (level == ans.size()) ans.add(node.val); // first node seen at this level!
   - dfs(node.right, level + 1, ans); // right first!
   - dfs(node.left, level + 1, ans);

4. WHY THIS WORKS?
--------------------------------------------------------------------------------
Because `node.right` is called before `node.left`, the rightmost branch claims slot `ans[level]` first. Subsequent visits to the same level find `ans.size() > level` and are ignored.

5. WHY NOT OTHER APPROACHES (WHY NOT THAT)?
--------------------------------------------------------------------------------
Why not BFS?
BFS takes O(W) queue memory (up to N/2 nodes). Recursive DFS uses only O(H) stack memory and is only 5 lines of code.

6. STEP-BY-STEP DRY RUN
--------------------------------------------------------------------------------
Tree: 1 with left: 2, right: 3 -> 2 has right: 5, 3 has right: 4
- node 1: level 0 == ans.size(0) -> add 1 -> ans=[1]
- go right to 3: level 1 == ans.size(1) -> add 3 -> ans=[1, 3]
- go right to 4: level 2 == ans.size(2) -> add 4 -> ans=[1, 3, 4]
- backtrack, visit 2: level 1 < ans.size(3) -> skip!
- visit 5: level 2 < ans.size(3) -> skip!
Right View: [1, 3, 4]

7. COMPLEXITY ANALYSIS
--------------------------------------------------------------------------------
- Time Complexity: O(N)
  Reason: Visits each node once.
- Space Complexity: O(H)
  Reason: Recursion stack depth.

8. IMPORTANT TIPS, TRAPS & EDGE CASES
--------------------------------------------------------------------------------
- For Left View, simply swap the recursive calls: call `node.left` before `node.right`.
