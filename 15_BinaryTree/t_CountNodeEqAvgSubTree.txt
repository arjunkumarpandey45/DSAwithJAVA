================================================================================
QUESTION: Count Nodes Equal to Average of Subtree (LeetCode 2265)
FILE: t_CountNodeEqAvgSubTree.java
================================================================================

1. WHAT IS THIS PROBLEM ABOUT?
--------------------------------------------------------------------------------
Given the root of a binary tree, return the number of nodes where the value of the node is equal to the average of the values in its subtree (rounded down to nearest integer).

2. HOW TO THINK (INTUITION)?
--------------------------------------------------------------------------------
To know the average of a subtree, you need two things:
1. The sum of all nodes in the subtree.
2. The total count of nodes in the subtree.
Average = `sum / count`.
Postorder DFS: Each recursive call returns a pair `[sum, count]` to its parent!
If `root.val == sum / count`, increment our answer count!

3. STEP-BY-STEP APPROACH
--------------------------------------------------------------------------------
1. int[] ans = new int[1];
2. dfs(root, ans):
   - if (root == null) return new int[]{ 0, 0 }; // sum=0, count=0
   - int[] left = dfs(root.left, ans);
   - int[] right = dfs(root.right, ans);
   - int sum = left[0] + right[0] + root.val;
   - int count = left[1] + right[1] + 1;
   - if (root.val == sum / count) ans[0]++;
   - return new int[]{ sum, count };
3. Return ans[0].

4. WHY THIS WORKS?
--------------------------------------------------------------------------------
Postorder combines bottom-up information in a single pass without re-traversing subtrees.

5. WHY NOT OTHER APPROACHES (WHY NOT THAT)?
--------------------------------------------------------------------------------
Top-down calling `sum(node)` and `count(node)` for every node takes O(N^2). Bottom-up returns `[sum, count]` in O(N).

6. STEP-BY-STEP DRY RUN
--------------------------------------------------------------------------------
Tree: 4 -> left: 8 (children 0, 1), right: 5 (child 6)
Node 0: sum=0, count=1 -> avg=0 == 0 -> match! (1)
Node 1: sum=1, count=1 -> avg=1 == 1 -> match! (2)
Node 8: sum=0+1+8=9, count=3 -> avg=9/3=3 != 8
Node 6: sum=6, count=1 -> avg=6 == 6 -> match! (3)
Node 5: sum=5+6=11, count=2 -> avg=11/2=5 == 5 -> match! (4)
Node 4: sum=9+11+4=24, count=6 -> avg=24/6=4 == 4 -> match! (5)
Output: 5 nodes.

7. COMPLEXITY ANALYSIS
--------------------------------------------------------------------------------
- Time Complexity: O(N)
  Reason: Single postorder pass.
- Space Complexity: O(H)
  Reason: Recursion stack.

8. IMPORTANT TIPS, TRAPS & EDGE CASES
--------------------------------------------------------------------------------
- Integer division `sum / count` automatically performs floor rounding as required.
