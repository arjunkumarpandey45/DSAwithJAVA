================================================================================
QUESTION: Insert into a Binary Search Tree (LeetCode 701)
FILE: b_InsertIntoBST.java
================================================================================

1. WHAT IS THIS PROBLEM ABOUT?
--------------------------------------------------------------------------------
Insert a value into a BST such that the BST properties remain valid.

2. HOW TO THINK (INTUITION)?
--------------------------------------------------------------------------------
Search for the value in the BST until you hit a null pointer!
That null position is the EXACT spot where the new node belongs!
Attach `new TreeNode(val)` to the parent node.

3. STEP-BY-STEP APPROACH
--------------------------------------------------------------------------------
1. if (root == null) return new TreeNode(val);
2. TreeNode curr = root;
3. while (true):
   - if (curr.val <= val):
     - if (curr.right != null) curr = curr.right;
     - else { curr.right = new TreeNode(val); break; }
   - else:
     - if (curr.left != null) curr = curr.left;
     - else { curr.left = new TreeNode(val); break; }
4. Return root;

4. WHY THIS WORKS?
--------------------------------------------------------------------------------
There is always an available leaf position where the new key satisfies all ancestor inequality constraints.

5. WHY NOT OTHER APPROACHES (WHY NOT THAT)?
--------------------------------------------------------------------------------
Inserting at a leaf is O(H) and preserves all existing tree pointers without rebalancing.

6. STEP-BY-STEP DRY RUN
--------------------------------------------------------------------------------
Tree: 4 -> (2, 7). Insert 5
- 5 > 4 -> go right to 7
- 5 < 7 -> left is null -> attach 5 to 7.left!
Tree remains a valid BST.

7. COMPLEXITY ANALYSIS
--------------------------------------------------------------------------------
- Time Complexity: O(H)
  Reason: Traverses down one branch.
- Space Complexity: O(1) iterative
  Reason: In-place pointer link.

8. IMPORTANT TIPS, TRAPS & EDGE CASES
--------------------------------------------------------------------------------
- Remember to handle empty tree: `if (root == null) return new TreeNode(val)`.
