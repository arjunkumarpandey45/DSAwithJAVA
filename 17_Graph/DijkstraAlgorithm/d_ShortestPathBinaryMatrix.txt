================================================================================
QUESTION: Shortest Path in Binary Matrix (LeetCode 1091)
FILE: d_ShortestPathBinaryMatrix.java
================================================================================

1. WHAT IS THIS PROBLEM ABOUT?
--------------------------------------------------------------------------------
Given an n x n binary matrix grid, return the length of the shortest clear path from top-left (0, 0) to bottom-right (n-1, n-1) with 8-directional movement. 0 is clear, 1 is blocked.

2. HOW TO THINK (INTUITION)?
--------------------------------------------------------------------------------
All edges have weight 1 (each move takes 1 step).
Shortest path with unit weights = STANDARD BFS!
No Dijkstra priority queue needed; a simple FIFO queue is faster and optimal!
Explore all 8 directions from current cell.

3. STEP-BY-STEP APPROACH
--------------------------------------------------------------------------------
1. if (grid[0][0] != 0 || grid[n-1][n-1] != 0) return -1;
2. if (n == 1) return 1;
3. Queue<int[]> q = new LinkedList<>(); q.offer(new int[]{ 0, 0, 1 }); // r, c, dist
   grid[0][0] = 1; // mark visited
4. while (!q.isEmpty()):
   - curr = q.poll();
   - for 8 directions (dr, dc):
     - nr = curr[0] + dr, nc = curr[1] + dc;
     - if (nr == n - 1 && nc == n - 1) return curr[2] + 1; // destination!
     - if (valid && grid[nr][nc] == 0): grid[nr][nc] = 1; q.offer(new int[]{ nr, nc, curr[2] + 1 });
5. Return -1;

4. WHY THIS WORKS?
--------------------------------------------------------------------------------
Unweighted 8-directional graph BFS guarantees the first time (n-1, n-1) is visited is via the minimum number of steps.

5. WHY NOT OTHER APPROACHES (WHY NOT THAT)?
--------------------------------------------------------------------------------
Dijkstra adds log(N^2) heap overhead. BFS achieves O(N^2) without heap.

6. STEP-BY-STEP DRY RUN
--------------------------------------------------------------------------------
grid = [[0, 1], [1, 0]]
Move diagonally from (0,0) directly to (1,1): length = 2!

7. COMPLEXITY ANALYSIS
--------------------------------------------------------------------------------
- Time Complexity: O(N^2)
  Reason: Each cell visited once.
- Space Complexity: O(N^2)
  Reason: Queue storing coordinates.

8. IMPORTANT TIPS, TRAPS & EDGE CASES
--------------------------------------------------------------------------------
- Remember there are EIGHT directions (including 4 diagonals).
