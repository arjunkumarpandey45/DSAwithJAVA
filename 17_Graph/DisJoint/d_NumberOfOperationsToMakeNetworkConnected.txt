================================================================================
QUESTION: Number of Operations to Make Network Connected (LeetCode 1319)
FILE: d_NumberOfOperationsToMakeNetworkConnected.java
================================================================================

1. WHAT IS THIS PROBLEM ABOUT?
--------------------------------------------------------------------------------
Given n computers and connections, you can extract cables from existing connections and re-route them. Return the minimum operations to connect all computers, or -1 if impossible.

2. HOW TO THINK (INTUITION)?
--------------------------------------------------------------------------------
To connect `N` computers into one network, you need AT LEAST `N - 1` cables.
If `connections.length < n - 1`, return -1 immediately!
Now use DSU:
Count the number of disconnected components `C`.
To connect `C` separate components together, you need exactly `C - 1` cables!
Since we already verified we have enough total cables, the answer is simply `C - 1`!

3. STEP-BY-STEP APPROACH
--------------------------------------------------------------------------------
1. if (connections.length < n - 1) return -1;
2. DSU dsu = new DSU(n); int components = n;
3. For each edge [u, v]:
   - if (dsu.findUPar(u) != dsu.findUPar(v)):
     - dsu.unionBySize(u, v);
     - components--;
4. Return components - 1;

4. WHY THIS WORKS?
--------------------------------------------------------------------------------
Each union of previously disconnected components reduces the number of components by 1. Connecting `C` islands requires `C - 1` bridges.

5. WHY NOT OTHER APPROACHES (WHY NOT THAT)?
--------------------------------------------------------------------------------
Tracking redundant cables explicitly is unnecessary; checking `edges >= n - 1` guarantees enough redundant cables exist.

6. STEP-BY-STEP DRY RUN
--------------------------------------------------------------------------------
n = 4, connections = [[0,1],[0,2],[1,2]], total edges = 3 >= 4 - 1 = 3.
Components: {0, 1, 2} and {3} -> 2 components.
Operations needed = 2 - 1 = 1 move!

7. COMPLEXITY ANALYSIS
--------------------------------------------------------------------------------
- Time Complexity: O(E * alpha(V))
  Reason: One DSU union per connection.
- Space Complexity: O(V)
  Reason: DSU arrays.

8. IMPORTANT TIPS, TRAPS & EDGE CASES
--------------------------------------------------------------------------------
- Check `connections.length < n - 1` FIRST before doing any DSU work.
