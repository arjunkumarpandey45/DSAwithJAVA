================================================================================
QUESTION: Graph Depth First Search (DFS)
FILE: b_GraphDFS.java
================================================================================

1. WHAT IS THIS PROBLEM ABOUT?
--------------------------------------------------------------------------------
Traverse a graph by exploring as deep as possible along each branch before backtracking.

2. HOW TO THINK (INTUITION)?
--------------------------------------------------------------------------------
Like exploring a labyrinth with a ball of string:
Walk down a hallway as far as you can.
When you hit a dead end (already visited nodes or no neighbors), backtrack to the last intersection and try the next path.

3. STEP-BY-STEP APPROACH
--------------------------------------------------------------------------------
1. boolean[] vis = new boolean[V];
2. dfs(node, adj, vis, ans):
   - vis[node] = true;
   - ans.add(node);
   - for each neighbor in adj.get(node):
     - if (!vis[neighbor]) dfs(neighbor, adj, vis, ans);

4. WHY THIS WORKS?
--------------------------------------------------------------------------------
Recursion uses the call stack to explore one full branch to its termination before unwinding to explore sibling branches.

5. WHY NOT OTHER APPROACHES (WHY NOT THAT)?
--------------------------------------------------------------------------------
DFS uses less memory than BFS on wide graphs (stack is O(H) vs queue O(W)) and naturally supports topological sorting and cycle detection.

6. STEP-BY-STEP DRY RUN
--------------------------------------------------------------------------------
Adj: 0-[1, 2], 1-[0, 3], 2-[0], 3-[1]
dfs(0): vis[0]=true, visit 1
dfs(1): vis[1]=true, visit 3
dfs(3): vis[3]=true, dead end -> backtrack to 1 -> backtrack to 0
dfs(0) continues to neighbor 2: vis[2]=true
DFS Order: [0, 1, 3, 2]

7. COMPLEXITY ANALYSIS
--------------------------------------------------------------------------------
- Time Complexity: O(V + 2E)
  Reason: Each vertex visited once, each edge checked twice.
- Space Complexity: O(V)
  Reason: Recursion call stack in skewed graph.

8. IMPORTANT TIPS, TRAPS & EDGE CASES
--------------------------------------------------------------------------------
- For disconnected graphs, run DFS in a loop over all vertices 0 to V - 1: `if (!vis[i]) dfs(i)`.
