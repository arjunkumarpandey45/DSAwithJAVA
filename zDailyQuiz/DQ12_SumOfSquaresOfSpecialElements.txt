================================================================================
QUESTION: DQ12 - Sum of Squares of Special Elements
FILE: DQ12_SumOfSquaresOfSpecialElements.JAVA
================================================================================

1. WHAT IS THIS PROBLEM ABOUT?
--------------------------------------------------------------------------------
You are given a 1-indexed integer array 'nums' of length n.
An element nums[i - 1] is called special if 'i' divides 'n', i.e., n % i == 0.
Return the sum of the squares of all special elements of nums.

2. HOW TO THINK (INTUITION)?
--------------------------------------------------------------------------------
This is a direct math simulation:
1. Array is 1-indexed, meaning index i ranges from 1 to n.
2. Check if i is a divisor of n (n % i == 0).
3. If it is, square the element at (i - 1) and add to total sum.

3. STEP-BY-STEP APPROACH
--------------------------------------------------------------------------------
1. Let n = nums.length, ans = 0.
2. Loop i from 1 to n:
   - If n % i == 0:
     * ans += nums[i - 1] * nums[i - 1]
3. Return ans.

4. WHY THIS WORKS?
--------------------------------------------------------------------------------
The problem definition explicitly asks to sum nums[i-1]^2 for all divisors i of n.
Iterating all numbers 1 to n checks every possible divisor without omission.

5. WHY NOT OTHER APPROACHES (WHY NOT THAT)?
--------------------------------------------------------------------------------
Can we iterate up to sqrt(n)?
- For very large n, iterating up to sqrt(n) and adding both i and n/i is O(sqrt(n)).
- But for typical constraints (n <= 100), simple O(n) loop is trivial, clean, and bug-free.

6. STEP-BY-STEP DRY RUN
--------------------------------------------------------------------------------
Input: nums = [1, 2, 3, 4], n = 4

i = 1: 4 % 1 == 0 -> special! ans += nums[0]^2 = 1^2 = 1.
i = 2: 4 % 2 == 0 -> special! ans += nums[1]^2 = 2^2 = 4 (ans = 5).
i = 3: 4 % 3 != 0 -> skip.
i = 4: 4 % 4 == 0 -> special! ans += nums[3]^2 = 4^2 = 16 (ans = 21).

Return 21.

7. COMPLEXITY ANALYSIS
--------------------------------------------------------------------------------
- Time Complexity: O(n)
  Reason: Simple loop from 1 to n.
- Space Complexity: O(1)
  Reason: Only one accumulator integer variable.

8. IMPORTANT TIPS, TRAPS & EDGE CASES
--------------------------------------------------------------------------------
- 1-indexed problem statement: 1-indexed i corresponds to 0-indexed nums[i - 1].
- 1 and n are always divisors of n.
