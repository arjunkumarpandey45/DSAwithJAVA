QUESTION: DQ2 - Count Commas
FILE: DQ2_CountCommas.java
================================================================================

1. WHAT IS THIS PROBLEM ABOUT?
--------------------------------------------------------------------------------
In standard number formatting, commas are placed every three digits from right to left (thousand separators):
  - Numbers 1 to 999 have 0 commas.
  - Numbers 1,000 to 999,999 have 1 comma.
  - Numbers 1,000,000 to 999,999,999 have 2 commas.
  - Numbers 1,000,000,000 to 999,999,999,999 have 3 commas, etc.
Given a positive integer 'n', calculate the total number of commas written when writing all numbers from 1 to n.

2. HOW TO THINK (INTUITION)?
--------------------------------------------------------------------------------
Instead of counting how many commas each individual number gets, flip your perspective:
Count commas by tiers / layers!
1. Every number >= 1,000 gets at least 1 comma. How many such numbers? (n - 1000 + 1) = (n - 999).
2. Every number >= 1,000,000 gets a 2nd comma. How many? (n - 999,999).
3. Every number >= 1,000,000,000 gets a 3rd comma. How many? (n - 999,999,999).
By summing up the contributions of each tier, we find the total commas in O(1) mathematical steps!

3. STEP-BY-STEP APPROACH
--------------------------------------------------------------------------------
1. Initialize ans = 0.
2. If n >= 1,000: add (n - 999) to ans.
3. If n >= 1,000,000: add (n - 999,999) to ans.
4. If n >= 1,000,000,000: add (n - 999,999,999) to ans.
5. If n >= 10^12: add (n - (10^12 - 1)) to ans.
6. If n >= 10^15: add (n - (10^15 - 1)) to ans.
7. Return ans.

4. WHY THIS WORKS?
--------------------------------------------------------------------------------
Layered counting (contribution technique):
A number like 1,500,000 is >= 1,000 (adds 1 to ans) AND >= 1,000,000 (adds 1 to ans).
Total commas added for 1,500,000 = 1 + 1 = 2 commas. Exactly correct!

5. WHY NOT OTHER APPROACHES (WHY NOT THAT)?
--------------------------------------------------------------------------------
Why not loop i from 1 to n and count commas for each number?
- If n = 10^9 or 10^12, looping to n will take minutes to hours or cause Time Limit Exceeded.
  The math tier approach runs in instantaneous O(1) time.

6. STEP-BY-STEP DRY RUN
--------------------------------------------------------------------------------
Input: n = 1000000 (1 Million)

ans = 0
1. n >= 1000: ans += (1000000 - 999) = 999001
2. n >= 1000000: ans += (1000000 - 999999) = 1
3. n < 1000000000: skip

Total ans = 999001 + 1 = 999002.
Explanation: Numbers 1,000 to 999,999 (999,000 numbers) have 1 comma each (999,000 commas).
Number 1,000,000 has 2 commas. 999,000 + 2 = 999,002 commas.

7. COMPLEXITY ANALYSIS
--------------------------------------------------------------------------------
- Time Complexity: O(1)
  Reason: Fixed number of constant-time arithmetic checks and additions.
- Space Complexity: O(1)
  Reason: Only uses a single 64-bit integer variable (long).

8. IMPORTANT TIPS, TRAPS & EDGE CASES
--------------------------------------------------------------------------------
- Always use 'long' because the count of commas easily exceeds 32-bit Integer.MAX_VALUE.
- Remember literal 'L' suffix for large constants in Java (e.g. 1000000000000L).
